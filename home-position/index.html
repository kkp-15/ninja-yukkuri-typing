ホームポジションの覚え方（大人・シニア向け）

公開 2026年9月26日

左手の人差し指を F、右手の人差し指を J に置きます。この2つのキーには小さな出っぱりがあり、見なくても指で探せます。残りの指は、となりのキーに1本ずつ並べます。

覚えるのは「キーの場所」より「打ったら F と J に戻る」ことです。戻る場所が決まると、ほかのキーの位置も少しずつ手が覚えます。

指の置き場所

指左手右手
人差し指F（出っぱりあり）J（出っぱりあり）
中指DK
薬指SL
小指A;（れ）
親指2本とも スペースキー の上に軽く

人差し指は2列ぶんを受け持ちます。左の人差し指は F と となりの G、右の人差し指は J と となりの H です。上の段・下の段のキーも、置いた指のまっすぐ上と下を受け持ちます（左の中指なら E・D・C）。

覚え方は「出っぱりを探す」から

  1. F と J の出っぱりを指でなぞる。キーの表面の手前寄りに、小さな横線か点があります。ほとんどのキーボードにあり、ノートパソコンにもあります。
  2. 人差し指を2本とも出っぱりに乗せ、残りの指をとなりに並べる。左は A・S・D・F、右は J・K・L・;（れ）です。
  3. 1文字打つたびに、人差し指を出っぱりに戻す。最初は1文字ごとに戻して確かめてかまいません。
  4. 手元を見るのは、指の置き場所がずれたときだけ。ずれたら出っぱりを探し直します。

いきなり手元を見ずに打つ必要はありません。はじめはキーボードを見ながらでよく、「戻る場所」だけ守るのが続けるこつです。

日本語でよく使うキーは、このサイトのお題で数えると

「どのキーから覚えればいいか」を確かめるため、このサイトの練習のお題193問（はじめて73問・ふつう60問・むずかしい60問）を、練習画面に出る打ち方のとおりにローマ字にして、押すキーを数えました（2026年9月26日）。合計3,994回のキー入力です。

分かったこと割合
母音（A I U E O）が、押すキーのほぼ半分48.7%
いちばん多いのは A（左手の小指）14.4%
ホームポジションの段（A〜L）＋上の段の母音 I・U・E・O で68.3%
F と J のキーそのものを押す回数0.7%

ここから言えることは3つです。

  • F と J は「押すキー」ではなく「戻る場所」。押す回数はわずか0.7%です。出っぱりは、指を置き直すための目印です。
  • A を小指で押せると、全体の7分の1が楽になる。人差し指で A まで手をのばすと、そのたびに手の位置がずれます。
  • ホームポジションの段と、上の段の母音 4つで、打つキーの約7割。日本語のローマ字入力は、1文字ごとに母音を打つからです。

数え方: 「し」は si、「ん」は nn のように、練習画面のガイドに最初に出る打ち方で数えました。shi で打つ方は H が少し増えます。お題は暮らしの言葉・あいさつ文・ことわざで、ほかの文章では割合が変わります。

先に覚えると早いキーの順番

  1. ホームポジションの8つ（A S D F ／ J K L ;） — 指を置いた場所。とくに A（左小指）。
  2. 上の段の母音 4つ — I＝右の中指、U＝右の人差し指、O＝右の薬指、E＝左の中指。どれも、置いた指をまっすぐ上にのばした所です。
  3. よく出る子音 — お題では N（8.4%・右人差し指）、S（7.0%・左薬指）、T（5.9%・左人差し指）、K（5.8%・右中指）、M（4.6%・右人差し指）の順でした。
  4. 残りのキー — 「、」は ,（右中指）、「。」は .（右薬指）、のばす音「ー」は -（右小指）です。

ここまでで、ふだん打つ日本語のかなりの部分がそろいます。ローマ字の打ち方そのもの（「っ」「ん」など）は、ローマ字入力の早見表にまとめています。

大人・シニアがつまずきやすいところ

A を人差し指で押してしまう

小指は力が入りにくく、つい人差し指で押したくなります。A は一番よく押すキーなので、ここだけは遅くても小指で押すようにすると、手の位置がずれにくくなります。

右手が1つ右にずれる

右の人差し指が K に乗っていると、打つ文字が全部1つずれます。打ち間違いが続いたら、まず J の出っぱりを探し直してください。

手首をキーボードの手前に置いて、指が上の段に届かない

手首を机に押しつけると、上の段（I U O E）に指が届きにくくなります。手首は軽く浮かせるか、キーボードの手前にタオルなどを置いて高さをそろえると楽になります。

キーボードの文字が大文字なのが気になる

刻まれているのは大文字ですが、そのまま押せば小文字で入ります。日本語を打つときは Shift キーを使いません。

「ゆっくりタイピング」は、つぎに打つキーがキーボードの図で光り、その下に並んだ指10本のうち、使う指だけ色が変わります。F と J には印をつけています。時間制限はありません。

練習を始める（無料・登録不要）

「はじめて・5問」は、お題の平均で31回ほどのキー入力です。数分で終わります。

よくある質問

ホームポジションは覚えないといけませんか？
手元を見ながら打つだけなら、なくても打てます。手元を見ずに打てるようになりたいときは、指の戻る場所が決まっていないとキーの位置を覚えられないので、覚えるのが近道です。
F と J の出っぱりはどこにありますか？
F と J のキーの表面の手前寄りに、小さな横線か点の出っぱりがあります。ほとんどのキーボードにあり、ノートパソコンにもあります。指先でなぞると分かります。
A を小指で押すのがつらいです。
はじめは誰でも小指が遅く、力も入りにくいものです。ゆっくりでよいので小指で押し続けると慣れてきます。このサイトのお題では、A は打つキー全体の14%をしめる一番よく押すキーなので、ここを小指で押せると後が楽になります。
