タイピング上達のコツ（毎日何分・どの順で）

公開 2026年9月26日

1回は短く、毎日。まとめて長く練習するより、短い練習を毎日くり返すほうが覚えやすい、という研究があります。はじめは「はじめて・5問」（数分）から。

順番は「正確さ → 指の戻る場所 → よく使うキー → 速さ」。速さは最後で大丈夫です。

毎日何分？ — 長く1回より、短く毎日

キーボードの覚え方について、よく引用される研究があります。郵便局員の4つの組に、1回1時間か2時間の練習を、1日1回か2回行ってもらい、覚える速さを比べたものです（Baddeley と Longman、1978年）。

  • いちばん効率よく覚えたのは 「1日1回・1時間」 の組。いちばん効率が悪かったのは「1日2回・2時間ずつ」の組でした。
  • 1か月・3か月・9か月あけて測り直すと、速さは約3割落ちていました。ここでも「1日2回・2時間ずつ」の組がいちばん悪い結果でした。
  • 研究した人たちは、キーボードの練習は、できるなら時間を分けて続けるほうがよい、とまとめています。

この研究は郵便局で働く人を調べたもので、高齢の方を調べたものではありません。「何分なら正解」という答えではなく、「詰め込むより分けたほうがよい」という向きの話として読んでください。

このサイトの練習なら、どれくらいの長さ？

お題193問をローマ字にして、1回ぶんのキー入力の数を数えました（2026年9月26日）。

難しさお題の例5問でのキー入力（平均）
はじめて（73問）あさひ／さくら／ゆっくり約31回
ふつう（60問）おはようございます約119回
むずかしい（60問）ちりもつもればやまとなる約175回

「はじめて・5問」はキー入力30回ほどなので、ゆっくり打っても数分で終わります。まずはこれを毎日1回。物足りなくなったら10問、20問、または「ふつう」へ進んでください。

休みのとり方（厚生労働省の指針）

厚生労働省の「情報機器作業における労働衛生管理のためのガイドライン」は、職場でのパソコン作業について、続けて作業するのは1時間を超えないようにし、次までに10〜15分の休みを入れ、1時間の中でも1〜2回、1〜2分の小休止をとるよう示しています。職場向けの指針ですが、目や肩の疲れを防ぐ目安になります。

どの順で練習する？

  1. 正確さを先に。時間を気にせず、1問ずつ間違えずに打ちます。急ぐと、手元を見る癖や、決まっていない指で打つ癖がつきやすくなります。
  2. 指の戻る場所を決める。左手の人差し指を F、右手の人差し指を J に置き、1文字打つたびにそこへ戻します。くわしくはホームポジションの覚え方へ。
  3. よく使うキーから覚える。お題193問で数えると、キー入力のほぼ半分（48.7%）は母音の A・I・U・E・O でした。ホームポジションの段と、上の段の I・U・E・O を合わせると約7割です。ここが打てると、あとは子音のキーを足していくだけです。
  4. 難しさを上げる。「はじめて」で短い言葉 → 「ふつう」であいさつ文 → 「むずかしい」でことわざ、の順です。のばす音「ー」は「はじめて」のカタカナ語（キーボードなど）から、「、」「。」は「ふつう」から出てきます。
  5. 手元を見ない練習は、そのあとで。練習画面のキーボードの図で、つぎに打つキーと使う指が光ります。場所を覚えてきたら「キーボードの図をかくす」で消して、画面だけを見て打ちます。
  6. 速さは最後。正確に打てる回数が増えると、速さはあとからついてきます。

続けるための工夫

記録は「前回の自分」とだけ比べる

結果の画面には、今回と前回の「せいかくさ」「1分あたり」が並びます。人と比べる必要はありません。正確さが少しずつ上がっていれば、練習はうまくいっています。

同じお題ばかりにならないようにする

お題は193問あり、一周するまで同じお題は出ません。このサイトで練習を最後まで終えた方は、2026年8月22日〜9月18日の28日間に11人。その11人で合わせて119回、1人あたり約11回くり返し練習していました。くり返すほど、同じお題が続くと飽きてしまうので、お題を増やしてきました。

ローマ字の表を横に置く

ローマ字の打ち方があやふやなうちは、覚えようとするより、表を見ながら打つほうが続きます。ローマ字入力の早見表はA4用紙1枚に大きな文字で印刷できます。

姿勢と画面

  • 画面は目から 40cm 以上 はなし、画面の上のふちが目の高さと同じか、少し下になるようにします（厚生労働省の同じ指針）。
  • ひじがほぼ直角になる高さにキーボードを置き、手首は机に押しつけず軽く浮かせます。
  • 文字が見えにくいときは、練習画面の右上の「文字を大きく」を押してください。

「ゆっくりタイピング」は時間制限がなく、つぎに打つキーと使う指がキーボードの図で光ります。登録はいりません。

よくある質問

1日に何分練習すればいいですか？
決まった正解はありませんが、長く1回より、短く毎日のほうが覚えやすいという研究があります。このサイトの「はじめて・5問」は数分で終わるので、まずは毎日5問から始め、慣れたら10問、20問と増やしてください。続けて打つのは長くても1時間までにして、あいだに休みを入れます。
速さと正確さ、どちらを先に練習しますか？
正確さが先です。急ぐと手元を見る癖や、決まっていない指で打つ癖がつきやすくなります。このサイトは時間制限がないので、1問ずつ間違えずに打つことだけを考えてください。
しばらく休むと忘れてしまいますか？
キーボード練習の研究では、数か月あけると速さが約3割落ちていました。ただし、覚えたことが消えるわけではありません。休んだあとは「はじめて」に戻って、指ならしをしてから進めると戻りが早くなります。
